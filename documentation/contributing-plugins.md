# Contributing Plugins

`strata-performance-setup.sh` uses a modular, lazy-loaded plugin architecture with two plugin categories:

1. **LLM Host Plugins (`plugins/hosts/<id>.sh`)** — Install, update, manage services, and benchmark LLM inference servers (e.g. `strata.sh`). Loaded on demand when selected from the Index page or passed via `--plugin <id>`.
2. **Performance Tweak Packs (`plugins/tweaks/<pack>.sh`)** — Host/hardware optimization steps grouped by platform/vendor (`linux-core.sh`, `linux-laptop.sh`, `nvidia.sh`, `amd.sh`, `intel.sh`, `jetson.sh`, `macos.sh`, `common.sh`). Loaded automatically based on detected OS and hardware.

---

## Folder & Naming Conventions

```text
plugins/
  registry.tsv                 # Generated by ./scripts/gen-registry.sh (do not edit by hand)
  hosts/
    _template.sh               # Starter template for LLM host plugins
    <id>.sh                    # Lowercase alphanumeric/hyphen ID, matching --id "<id>"
  tweaks/
    _template.sh               # Starter template for tweak packs
    <pack>.sh                  # Platform/vendor pack name
```

## Creating an LLM Host Plugin (`plugins/hosts/<id>.sh`)

1. Copy `plugins/hosts/_template.sh` to `plugins/hosts/<id>.sh`.
2. Add the 3-line metadata header at the top:
   ```bash
   # PLUGIN_ID: ollama
   # PLUGIN_NAME: Ollama
   # PLUGIN_DESC: Install, configure, and benchmark Ollama LLM server
   ```
3. Call `register_host_plugin`:
   ```bash
   register_host_plugin \
     --id "ollama" \
     --name "Ollama" \
     --description "Install, configure, and benchmark Ollama LLM server"
   ```
4. Implement the required hooks:
   - `<id>_init()` — Called once after sourcing; detect binary/container/version or start pollers.
   - `<id>_menu_row(selected)` — Print a 1-line status row for the Index page.
   - `<id>_open()` — Render and handle your interactive TUI subpage.
5. Implement optional hooks as needed:
   - `<id>_live_stats()` — Populate `LIVE_STAT_LINES` / `LIVE_COMPACT_STRATA` for `[STATS]`.
   - `<id>_check_summary()` — Print summary lines for `--check` / `[c]`.
   - `<id>_hw_warnings()` — Print hardware compatibility warnings above the Index.
   - `<id>_cleanup()` — Stop background pollers on exit.

## Creating or Adding a Performance Tweak (`plugins/tweaks/<pack>.sh`)

1. Open the matching pack in `plugins/tweaks/` (or copy `plugins/tweaks/_template.sh` for a new pack).
2. Register the step with `register_tweak`:
   ```bash
   register_tweak \
     --id "my_tweak" \
     --stars 4 \
     --tier "recommended" \       # recommended | opt_in | experimental | high_idle
     --os "linux" \               # linux | macos | both
     --laptop-recommended true \  # true | false
     --vm-supported true          # true | false
   ```
3. Implement all 6 standard step functions:
   - `applicable_<id>()` — Return `0` if applicable to the current host.
   - `title_<id>()` — Echo a concise title.
   - `status_<id>()` — Return `0` if currently applied.
   - `explain_<id>()` — Print impact/details.
   - `apply_<id>()` — Apply the optimization.
   - `revert_<id>()` — Cleanly revert the optimization.

## Shared Core Helpers (Reuse Instead of Reimplementing)

- **Privileges & prompts**: `run_root`, `run_as_user`, `confirm_yn`, `pause_prompt`
- **Services (systemd / launchd / SysVinit / Unraid / Synology)**: `install_service`, `remove_service`, `service_ctl`, `service_installed`, `unit_enabled`, `unit_active`
- **Packages**: `pkg_installed`, `pkg_available`, `pkg_install`, `aur_install`, `prompt_install_deps`
- **Kernel & sysctl**: `add_kernel_param`, `remove_kernel_param`, `has_kernel_param`, `kernel_param_value`, `write_sysctl_with_prev`, `restore_sysctl_prev`
- **TUI**: `print_header`, `read_step_action`, color variables (`C_BOLD`, `C_GREEN`, `C_YELLOW`, `C_CYAN`, `C_DIM`, `C_RESET`)

## Testing & Submitting a PR

1. Regenerate the plugin registry and checksums:
   ```bash
   ./scripts/gen-registry.sh
   ```
2. Run the full test suite:
   ```bash
   ./tests/test_strata_setup.sh
   ```
3. Test your plugin in read-only mode:
   ```bash
   ./strata-performance-setup.sh --plugin <id> --check
   ```
4. Commit your plugin file(s) and updated `plugins/registry.tsv` in your PR.
