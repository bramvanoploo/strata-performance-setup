# Live Dashboard & Strata Monitoring

The header and dedicated **`[STATS]`** / **`[STRATA]`** pages keep system and inference telemetry up to date without interrupting your input:

- **Live Dashboard (`[STATS]`):** Continuously refreshes every **1 second** across three stacked sections:
  - **System Information:** OS, kernel, Jetson board/L4T/SoC (when on Jetson) or Apple Silicon chip/model/macOS version (when on macOS), CPU model/threads (with P+E core split on Apple Silicon), RAM capacity/speed/timings/health warnings, GPU model(s), total VRAM (plus unified GTT pool size and `AMD HIP` `gfx` / local-build status on AMD APUs/GPUs, unified `GB10` memory on DGX Spark, or Apple Silicon unified memory + `iogpu.wired_limit_mb` cap on macOS), NVIDIA power limits, PCIe link/ReBAR status (checking hardware Resizable BAR capability to avoid false warnings on pre-ReBAR Tesla GPUs), and multi-GPU NUMA / NVLink / XGMI / PCIe ACS topology diagnostics.
  - **Live System Usage:** Color-coded bars for CPU usage + temperature (Mach `host_statistics` + `vm_stat` on macOS, including `applesmc` CPU temperature fallback on Intel Macs running Linux), RAM usage, per-GPU utilization + temperature (with live `[THROTTLE]` thermal-slowdown alerts and datacenter P-state indicators on NVIDIA, unified memory bars on DGX Spark `GB10`, combined VRAM+GTT unified memory tracking on AMD APUs, `xe` hwmon temp/wattage on Intel Arc Battlemage/Alchemist, Jetson `gp10b`/`gv11b`/`ga10b` load & thermal zones, and Apple Silicon `IOAccelerator` GPU utilization & wired allocation + `powermetrics` thermal pressure on macOS), and horizontal `Power:` (`GPU`, `CPU`, and `Sys` watts, including Jetson INA3221 rails across both L4T R32 `ina3221x` and L4T R35/R36 `hwmon`, and Apple Silicon `powermetrics` power rails on macOS).
    - *Tip:* On Linux x86 systems without a PSU or battery hwmon sensor, run with `sudo` (`sudo ~/strata-performance-setup.sh`) so the script can read root-only `intel-rapl` energy counters for `CPU` and `Sys` power; on macOS, run with `sudo` (or passwordless `sudo powermetrics`) for `powermetrics` GPU/CPU/Combined wattage and thermal pressure.
  - **Strata Live Telemetry:** Installed Strata version (or Docker container host-tuning mode), live running state & service status (`strata.service` on Linux / `com.strata.server` on macOS `launchd`), active serving preset and model, and live/session average `tok/s`. (Pass `--strata-api-key <key>` or set `STRATA_API_KEY` in the environment if your Strata instance requires an API key; the key is used for all Strata requests including `/metrics` polling and `strata bench run` benchmarks, with `--strata-api-key` overriding `STRATA_API_KEY`.)
- **Strata Options & Benchmark Summaries (`[STRATA]`):** Displays the **Latest**, **Previous**, and **Best** benchmark summaries (model, median & average decode/prefill `tok/s`, `%` diff vs. previous and vs. best, average power, and sanity/check counts) above the Strata lifecycle menu (`Install`, `Update`, `Remove`, `Service`, `Benchmark`, `History`, and `Build Local Strata HIP Engine` when applicable), with background polling for live `strata.service` / `com.strata.server` and benchmark readiness.
- **Active Update Polling:** Checks for Strata updates in the background every **60 seconds**, displays an `[UPDATE AVAILABLE]` banner on every screen when a new version is found, and lets you press `u` to open the Update Strata page, stop Strata (via service or `strata launch --stop`), run `strata update --yes`, restart the service if it was active, and notify you once the model is `[LIVE]` again.
