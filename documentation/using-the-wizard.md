# Using the Wizard

To inspect detected hardware, OS/init, or Docker container status, and which steps would apply without launching the TUI or making changes, run `./strata-performance-setup.sh --check` (or `./strata-performance-setup.sh --plugin strata --check` to include Strata status). For API-key-protected Strata instances, export `STRATA_API_KEY` (preferred — keeps the key out of shell history) or pass `--strata-api-key -` to be prompted silently (`--strata-api-key <key>` also works and overrides `STRATA_API_KEY`) so live `/metrics` telemetry, `strata bench run` benchmarks, and Strata CLI requests authenticate automatically (see `--help` for `--plugin` / `--with`, `--no-plugins`, `--list-plugins`, and `--download-plugins`).

Once launched, the main index lists `[STATS]` (live system metrics, plus host metrics once a host plugin is loaded), `[SERVERS]` (opens the lazy-loaded Inference Servers menu including Strata and other detected host plugins), and every optimization applicable to your machine along with its live `[APPLIED]` / `[NOT APPLIED]` status:

- Navigate the index with **`↑` / `↓`** and press **`Enter`** (or type a **step number**) to open `[STATS]`, `[SERVERS]`, or an optimization step, or press `w` to walk through the **guided wizard** step by step
- Press `c` on the index to view the read-only **Check / detection summary** inside the TUI (same OS, hardware, Strata, and step-applicability summary as `--check`)
- Open `[SERVERS]` → `Strata` for Strata lifecycle management (`s1`–`s6`, plus `s7` when `Build Local Strata HIP Engine` / `Manage Local Strata HIP Engine` applies: Install, Update, Remove, Service, Benchmark, Benchmark History, and local AMD HIP engine builds when an AMD GPU lacks an official prebuilt Strata Linux engine or a local build is installed) along with Latest, Previous, and Best benchmark summaries
- Press `a` to **apply all recommended optimizations** for your hardware in one action (with confirmation; excludes Strata setup and steps flagged with `[!]`, `[OPT]`, or `[EXP]`)
- Press `l` (shown on laptops, including MacBooks) to **apply laptop-recommended optimizations** (`[L]`) for minimal idle battery power impact and comfortable unplugged usage across any laptop vendor (additionally excludes sleep/lid-close masking, idle high-clock/persistence GPU settings, server-only fabric/MIG steps, and platform/vendor/macOS High Power profiles). When applying via `a` or `l`, any currently applied options outside that scope are listed so you can choose to revert them or leave them as is
- **Index Legend Flags** *(only flags relevant to your detected hardware/OS are shown below the index table)*:
  - `[!]` — Higher idle power, minimal gain (excluded from `[a]` and `[l]`, e.g., CPU Performance governor, deep C-state limit, PCIe ASPM, GPU clock lock, `tuned`)
  - `[OPT]` — Opt-in trade-off (excluded from `[a]` and `[l]`, e.g., Tesla/datacenter thermal power cap, AMD Instinct SPX/CPX partitioning, 1 GiB hugepages RAM reservation, macOS Metal wired memory limit `iogpu.wired_limit_mb`, Strata Metal engine switches)
  - `[EXP]` — Experimental / third-party or hardware-dependent (excluded from `[a]` and `[l]`, e.g., non-Arch `gpu-unlock`, `nvidia-pstated` idle P-state fix, multi-GPU PCIe ACS disable)
  - `[L]` — Laptop-recommended (low idle battery impact; shown on laptops)
- Press `x` to **revert all recommended optimizations** in one action (with confirmation)
- Press `u` (when shown) to open the **Update Strata** page, install a pending Strata update, and restart `strata.service` / `com.strata.server`
- Press `r` on the index to **reboot** the system (the wizard also prompts automatically whenever applying or reverting a change requires a reboot)
- Inside any step, press `a` to **apply** (when not yet applied), `r` to **revert** (when applied), `n` / `b` to move next/back, or `i` / `Esc` to return to the index
- Open **View All Benchmark Results & Coupled Options** (from `[SERVERS]` → `Strata`, or press `h` on the index to lazy-load Strata and open history) to browse full-width tables of all recorded benchmarks with median/average `tok/s`, average system/GPU/CPU power, and a vertical list of active optimizations; use **`↑` / `↓` + `Enter`** (or `[1-N]`) to restore a benchmark's host configuration (with `[y]` Apply / `[N/c/Esc]` Cancel confirmation). *(Note: after a cold model load, run a warmup pass before A/B comparing host optimizations—decode throughput can ramp over the first several probes as the engine warms up.)*
